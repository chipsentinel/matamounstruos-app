# Proyecto

Esta carpeta recoge documentacion sobre el desempeno del proyecto.

Aqui no se usa el prefijo `tarjeta-` porque estos archivos explican que se hizo en cada area, no son contenido directo para cargar como tarjetas.

Si quieres estudiar la parte tecnica directa, empieza por los archivos principales de `docs/`: `backend.md`, `frontend.md`, `database.md`, `testing.md`, `devops.md` y `git.md`.

Si quieres repasar contenido breve tipo tarjeta, usa `docs/tematica/`.

## Archivos

- [Guia de estudio](./guia-estudio.md): mapa rapido para entender el proyecto.
- [Arquitectura](./arquitectura.md): flujo entre frontend, backend y base de datos.
- [Backend](./backend.md): desempeno del servidor y API REST.
- [Frontend](./frontend.md): desempeno de la interfaz React.
- [Base de datos](./base-datos.md): desempeno del modelo de datos.
- [Flujo funcional](./flujo-funcional.md): como se conecta el juego con cartas y tarjetas.
- [Docker](./docker.md): contenedores y entorno reproducible.
- [Gitflow](./gitflow.md): ramas, commits y pull requests.
- [Postman](./postman.md): pruebas de integracion.
- [GitHub Actions](./github-actions.md): workflow de CI.

## Como usar esta carpeta

1. Lee primero [Guia de estudio](./guia-estudio.md).
2. Revisa [Arquitectura](./arquitectura.md) para entender el flujo completo.
3. Entra en cada archivo de desempeno para recordar que se hizo, por que se hizo y como se comprobo.
4. Usa los archivos tecnicos de `docs/` cuando necesites una explicacion mas directa del codigo.
