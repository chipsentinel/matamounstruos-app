# Tarjetas: Testing

## Test unitario

Un test unitario comprueba una funcion pequena sin levantar toda la aplicacion.

## Test de integracion

Un test de integracion comprueba que varias partes funcionan juntas, como ruta, controlador y base de datos.

## Postman

Postman permite enviar peticiones a la API y comprobar las respuestas.

## Newman

Newman ejecuta una coleccion de Postman desde la terminal.

## Assertion

Una assertion comprueba que una respuesta cumple lo esperado, como devolver `200` o un mensaje concreto.

## CI

La integracion continua ejecuta comprobaciones automaticamente cuando se suben cambios.
