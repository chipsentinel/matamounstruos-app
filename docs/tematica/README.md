# Tematica

Esta carpeta contiene solo contenido de tarjetas.

No incluye guias largas, comandos ni explicaciones de construccion del proyecto. Para eso estan las carpetas tecnicas de `docs/`.

## Formato recomendado

Cada tarjeta debe tener:

- Titulo claro.
- Contenido breve.
- Una idea principal por tarjeta.

Ejemplo:

```md
# Tarjeta: API REST

Una API REST permite que el frontend hable con el backend usando rutas HTTP como GET, POST, PUT y DELETE.
```
