# Tarjetas: Git, Docker y workflow

## Rama

Una rama permite trabajar una funcionalidad sin mezclarla directamente con el codigo principal.

## Commit

Un commit guarda un cambio concreto con un mensaje que explica la intencion.

## Pull Request

Un Pull Request permite revisar los cambios antes de fusionarlos.

## Docker

Docker permite levantar la aplicacion en contenedores para que el entorno sea mas repetible.

## Docker Compose

Docker Compose levanta varios servicios juntos, como base de datos, backend y frontend.

## GitHub Actions

GitHub Actions ejecuta tareas automaticas como instalar dependencias, lanzar tests y construir el frontend.
