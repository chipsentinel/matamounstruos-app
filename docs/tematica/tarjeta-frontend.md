# Tarjetas: Frontend

## React

React permite construir la interfaz con componentes reutilizables y estado.

## Vista

Una vista representa una pantalla principal de la aplicacion, como barajas, cartas, tarjetas o juego.

## Componente

Un componente es una pieza reutilizable de interfaz, como la navbar o la tarjeta de usuario.

## api.js

`api.js` centraliza las llamadas al backend para que las vistas no repitan URLs ni logica de `fetch()`.

## Estado

El estado guarda datos que pueden cambiar, como listas, formularios, usuario activo o carta actual.

## SweetAlert2

SweetAlert2 muestra mensajes visuales claros cuando una accion sale bien o falla.
