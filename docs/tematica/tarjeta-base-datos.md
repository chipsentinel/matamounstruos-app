# Tarjetas: Base de datos

## Tabla

Una tabla guarda datos de una entidad concreta, como usuarios, barajas, cartas o tarjetas.

## Clave primaria

La clave primaria identifica de forma unica cada registro de una tabla.

## Clave foranea

La clave foranea conecta una tabla con otra, por ejemplo una baraja con su usuario.

## Relacion uno a muchos

Un usuario puede tener muchas barajas, pero cada baraja pertenece a un usuario.

## Seeds

Los seeds son datos iniciales que ayudan a probar la aplicacion sin crear todo desde cero.

## Borrado

Al borrar datos hay que tener en cuenta las relaciones para no dejar registros dependientes sin sentido.
